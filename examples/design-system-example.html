03Components

ทุก component ใช้ค่าจาก token ด้านบนเท่านั้น — ไม่มีสีหรือขนาดที่ hardcode

Button

Variants
Sizes — S / M / L
States
✓ ใช้เมื่อไหร่Primary = การกระทำหลักของหน้า มีได้ 1 ปุ่มต่อหน้าจอ · Secondary = ทางเลือกรอง · Ghost = ยกเลิก/ปิด · Destructive = ลบหรือยกเลิกการจองเท่านั้น
✗ ไม่ควรใช้เมื่อไหร่อย่าวาง Primary สองปุ่มติดกัน · อย่าใช้สีแดงกับปุ่มที่ไม่ได้ลบข้อมูล · Secondary ใช้พื้นอ่อน + ตัวอักษรเข้ม เพราะตัวอักษรขาวบน #B9A8F5 contrast ไม่ผ่าน AA

Input · Select · Checkbox

ไม่เกิน 40 ตัวอักษร
รูปแบบอีเมลไม่ถูกต้อง
✓ ใช้เมื่อไหร่มี label เหนือช่องเสมอ · ข้อความ error บอกวิธีแก้ ไม่ใช่แค่ "ผิด" · Select ใช้เมื่อมีตัวเลือก 4 ข้อขึ้นไป
✗ ไม่ควรใช้เมื่อไหร่อย่าใช้ placeholder แทน label · อย่าแสดง error ก่อนผู้ใช้พิมพ์เสร็จ · ตัวเลือก 2–3 ข้อใช้ radio/checkbox แทน select
